# Student Performance Predictor

Predicts student exam performance using machine learning on academic and lifestyle factors (attendance, study hours, previous scores, sleep and more).

## Dataset
Kaggle "Student Performance Factors": 6,607 student records, 20 columns. Target: Exam_Score.

## Key findings so far
- Attendance (0.58) and hours studied (0.45) have the strongest link to exam score.
- Previous scores and tutoring sessions have a weak link (about 0.16 to 0.18).
- Sleep hours and physical activity show almost no link.
